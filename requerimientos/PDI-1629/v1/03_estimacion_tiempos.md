# 03 - Estimacion de tiempos

## Estimacion base

1. Refinamiento funcional final: 2h
2. API + Application: 8h
3. Infrastructure + BD: 4h
4. Pruebas unitarias y no regresion: 6h
5. OpenAPI + API docs + evidencias QA: 3h

Total base: 23h

## Contingencia

- Contingencia por ambiguedad funcional: 20%
- Reserva: 4.6h

Total estimado: 27.6h (redondeo operativo: 28h)

## Escenarios

- Paralelo: 2 a 3 dias habiles
- Secuencial: 4 a 5 dias habiles

## Supuestos

1. No hay cambios grandes de contrato.
2. La definicion del flujo se cierra temprano.
3. Hay acceso a ambientes de prueba.
