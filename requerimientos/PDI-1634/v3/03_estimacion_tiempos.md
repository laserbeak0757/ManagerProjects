# 03 - Estimacion de tiempos

## Estimacion base por frente

1. Refinamiento funcional final: 2h
2. API + Application (create/update/delete): 12h
3. Infrastructure + ajustes SP/queries: 6h
4. Pruebas unitarias y no regresion: 8h
5. OpenAPI + API docs + coleccion validacion: 4h

Total base: 32h

## Contingencia

- Contingencia por incertidumbre funcional: 20%
- Reserva: 6.4h

Total estimado: 38.4h (redondeo operativo: 38h a 40h)

## Escenarios

- Paralelo (2 personas): 4 a 5 dias habiles
- Secuencial (1 persona): 6 a 7 dias habiles

## Supuestos de calendario

1. Definicion funcional cerrada en dia 1.
2. Sin bloqueos de ambiente o acceso a BD.
3. QA disponible para validar durante la misma iteracion.
