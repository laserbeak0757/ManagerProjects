# SQL Server to PostgreSQL Mapping

Tipos de datos
- INTEGER -> integer
- BIGINT -> bigint
- SMALLINT -> smallint
- TINYINT -> smallint (o boolean segun semantica)
- BIT -> boolean
- DECIMAL(p,s) -> numeric(p,s)
- NUMERIC(p,s) -> numeric(p,s)
- DATETIME -> timestamp
- DATETIME2(n) -> timestamp (o timestamptz si se decide zona)
- DATE -> date
- NVARCHAR(n) -> varchar(n)
- VARCHAR(n) -> varchar(n)
- NVARCHAR(MAX) -> text
- TEXT/NTEXT -> text
- UNIQUEIDENTIFIER -> uuid

Identidad y claves
- IDENTITY(1,1) -> generated by default as identity
- SCOPE_IDENTITY() -> returning id

Defaults y funciones
- SYSUTCDATETIME() -> CURRENT_TIMESTAMP
- GETDATE() -> CURRENT_TIMESTAMP
- ISNULL(a,b) -> COALESCE(a,b)
- LEN(x) -> length(x)

DDL y sintaxis
- [schema].[table] -> schema.table
- [column] -> column
- GO -> remover
- ON [PRIMARY] -> remover
- WITH (...) en CREATE INDEX -> remover o mapear por caso
- CONSTRAINT names -> mantener cuando sea posible

Indices
- CREATE INDEX standard -> CREATE INDEX standard
- Filtered index SQL Server (WHERE ...) -> Partial index en PostgreSQL (WHERE ...)

Seeds
- MERGE -> preferir INSERT ... ON CONFLICT DO UPDATE

Features que requieren revision manual
- PERSISTED (columnas computadas)
- CHECK constraints complejos
- Colaciones especificas SQL Server
- Dependencias de transacciones por batch con GO

Recomendacion de zona horaria
- Si el sistema ya guarda UTC en SQL Server, mapear a timestamptz y normalizar en UTC.
